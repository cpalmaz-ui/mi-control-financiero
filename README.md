# Mi Control Financiero

Aplicación web instalable (PWA) sin datos bancarios precargados.

**Privacidad:** este repositorio es público y no debe contener estados de cuenta, importes ni respaldos personales. Los datos cargados por cada persona se almacenan solo en el navegador del dispositivo. Para usarla en varios equipos con los mismos pagos hace falta implementar autenticación y una base de datos privada. No subir archivos JSON de respaldo.

Publicación: Settings → Pages → Deploy from a branch → main → /(root) → Save.
